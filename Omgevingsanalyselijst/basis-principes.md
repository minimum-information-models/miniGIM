| Principe                                  | Toelichting                                                                                                                                                                                                                  |
|-------------------------------------------|------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| miniGIM Modules                           | De miniGIM informatie modules zijn een aanbeveling, geen verplichting.                                                                                                                                                       |
| Fasering                                  | Elke fase van verkaveling kan andere info vragen.                                                                                                                                                                            |
| Versie updates                            | Maak afspraken hoe om te gaan met updates van data tijdens een langdurig project.                                                                                                                                            |
| Beleidsaanpassingen                       | Sommige zaken zijn aanpasbaar, anderen niet. Maar deze vormen een integraal geheel.                                                                                                                                          |
| Nota van uitgangspunten / start briefing. | Maak duidelijk wat de uitgangspunten zijn. Bijvoorbeeld: parkeernorm is in geen enkel geval aan te passen. Simulatie-modellen zijn grof of fijn, en zijn op een bepaalde manier gekalibreerd. Stel vast hoe je dat wil doen. |
| Verschillende rollen                      | Let erop dat verschillende stakeholders verschillende rollen hebben en verschillende belangen vertegenwoordigen.                                                                                                             |
| Scenario's                                | Dit initiatief gaat niet zozeer over het verkrijgen van een eenduidige oplossing, maar over het ontdekken van verschillende scenario's.                                                                                      |
